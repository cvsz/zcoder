# UPGRADE-13: Zero-Cost Platform Architecture & Offline Local Stack

## Overview
Upgrade-13 establishes the 100% credential-free, air-gapped offline tier:

1. **Zero-Cost Core:**
   - Standalone CLI execution requiring zero commercial credentials.

2. **Local Model Routing:**
   - First-class support for Ollama, vLLM, and local OpenAI-compatible endpoints with automatic fallback suppression.

3. **Local Storage & Analytics:**
   - Filesystem-backed tenant sandboxed storage and SQLite in-memory analytics.
