# UPGRADE-22: Portfolio Scheduler, Worker Fleet & Campaign Execution

## Overview
Upgrade-22 expands zcoder to multi-tenant project portfolio scheduling and worker fleet orchestration:

1. **Portfolio Scheduler & Campaign Engine:**
   - Multi-project migration, security audit, and refactoring campaign coordination.

2. **Worker Fleet Management:**
   - Dynamic worker pool scaling with heartbeat monitoring and lease expiration handling.

3. **Concurrency & Resource Controls:**
   - Per-tenant worker concurrency caps and rate limit quotas.
