# zcoder master prompts

Start with ROADMAP.md (what and in what order), then run MASTER.prompt with one cycle prompt (U61…U76) per session. _SHARED.md applies to every cycle.

Each cycle outputs a patch, a source zip, and a report. Nothing is committed, pushed, approved, or merged by the agent; you do the GPG commit, push, independent review, and merge.

Facts are dated 2026-10-25 and must be re-verified live by the agent before coding.
