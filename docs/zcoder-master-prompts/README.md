# zcoder master prompts

Start with `ROADMAP.md` (what and in what order), then run `MASTER.prompt` with one cycle prompt per session. `_SHARED.md` applies to every cycle.

Current cycle prompts: U61–U76 and **U77 — Claude Code Capability Parity Program**. U77 begins with an audit-only Phase A; do not start broad implementation until the evidence-backed parity matrix and architecture report are reviewed.

Each cycle outputs a patch, a source zip, and a report. Nothing is committed, pushed, approved, or merged by the agent; the human performs the GPG commit, push, independent review, and merge.

All dated upstream facts must be re-verified against official sources at execution time. U77 planning estimates are unverified assumptions, not commitments.
